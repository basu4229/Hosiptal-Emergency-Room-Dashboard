# Hosiptal-Emergency-Room-Dashboard
🏥 Hospital Emergency Room Dashboard (Power BI)
📌 Project Overview

This project presents a comprehensive Emergency Room (ER) Analytics Dashboard built using Power BI, designed to improve hospital operations through data-driven insights.

The dashboard enables stakeholders to monitor patient flow, evaluate service efficiency, and identify areas for operational improvement across a 19-month period (April 2023 – October 2024).

🎯 Business Objective

The goal of this solution is to:

Enhance operational efficiency in the emergency room
Monitor patient management and service quality
Provide real-time insights for decision-making
Optimize resource allocation and staffing
📊 Key KPIs
Total Patients – Daily ER visits
Average Wait Time – Time before patients are attended
Patient Satisfaction Score – Service quality indicator
Total Referrals – Patients referred to departments

Each KPI is supported with daily trend (sparkline) analysis to identify patterns and anomalies.
